# 用 Google Sheet 維護行程與成員資料

網站會讀取「發佈到網路」的 Google Sheet CSV。你在試算表上改完，**約 5 分鐘內**網站就會更新，不用重新部署。

建議開 **兩份** 試算表：

| 試算表 | 誰可以編輯 | 用途 |
|---|---|---|
| 泰國行程 | 你＋想幫忙的家人（共編） | 行程 |
| 泰國成員 | **只有你** | 個人資料、入境卡連結 |

> 成員資料分開放，是因為共編者能看到整份試算表，包括其他人的入境卡連結。

---

## 一、建立試算表

1. 新增 Google 試算表 →「檔案 → 匯入 → 上傳」，選 `sheet-templates/行程.csv`（成員表就選 `成員.csv`）
   - 匯入位置選「**取代試算表**」
   - **取消勾選**「將文字轉換為數字、日期和公式」（時間才不會被改成「上午 9:30:00」）
2. 把整張表選起來 →「格式 → 數字 → **純文字**」（避免 Google 自動把時間轉成「上午 9:30:00」）
3. 第一列標題**不要改名、不要刪欄**，順序可以調整

## 二、發佈成 CSV

1. 「檔案 → 共用 → **發佈到網路**」
2. 連結區塊選「該工作表」（例如 `行程`），格式選「**逗號分隔值 (.csv)**」→ 發佈
3. 複製網址（長得像 `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?gid=0&single=true&output=csv`）
4. 貼到 `src/config.ts`：

```ts
export const SHEETS = {
  itinerary: 'https://docs.google.com/.../pub?gid=0&single=true&output=csv',
  members:   'https://docs.google.com/.../pub?gid=0&single=true&output=csv',
}
```

## 三、「行程」欄位說明（給共編的家人看）

每一列 = 一個行程。**時間一律填泰國時間**（比台灣慢 1 小時），除非「時區」欄填「台灣」。

| 欄位 | 必填 | 怎麼填 | 範例 |
|---|---|---|---|
| 日期 | ✅ | 年/月/日 | `2027/1/19` |
| 開始 | ✅ | 24 小時制 | `09:30` |
| 結束 | | 不填 = 預設 1 小時 | `12:00` |
| 標題 | ✅ | 簡短名稱 | `大皇宮` |
| 類型 | | 交通／景點／餐廳／購物／住宿／自由／其他 | `景點` |
| 地點 | | 給人看的地點名稱 | `大皇宮正門` |
| 地圖 | | Google Maps 分享連結 | `https://maps.app.goo.gl/...` |
| 連結 | | 餐廳 IG、門票、預約頁…任何網址 | |
| 備註 | | 提醒事項 | `需穿長褲` |
| 時區 | | 只有在台灣發生的行程填 `台灣`，其他留空 | `台灣` |

**小技巧**
- Google Maps 連結：在地圖 App 按「分享」→「複製連結」直接貼上
- 排列順序沒關係，網站會自動依時間排序
- 還沒確定的行程可以先填標題，例如 `晚餐（待定）`

## 四、「成員」欄位說明（只有你編輯）

| 欄位 | 說明 |
|---|---|
| 代碼 | 每人一組不重複的英數字（例如 `k7x2pq`），網站內部辨識用，填好後不要再改 |
| 姓名 | 顯示用 |
| 房間 | 分配到哪一間房，可留空 |
| 同房 | |
| 入境卡 | TDAC QR code 的連結（見下方） |
| 備註 | 給這個人的個別提醒 |
| 去程 | **只有自行搭機的人填**，自由文字，例如 `TG635 1/18 10:20 桃園→13:00 曼谷`；留空 = 搭團體班機 |
| 回程 | 同上 |

### 怎麼看到自己的資料

所有人都用同一個網址。到「我的」分頁點自己的名字，這支手機就會記住；要換人按「不是你？切換成員」。

### 入境卡（TDAC）連結

1. 申請完成後，把每個人的 QR code 截圖（或確認信 PDF）上傳到 Google Drive
2. 對檔案按「共用」→ 一般存取權改為「**知道連結的使用者**」→ 複製連結
3. 貼到該成員的「入境卡」欄

> ⚠️ 隱私提醒：這是靜態網站，懂技術的人只要知道網站網址，就有辦法找到發佈的 CSV，看到所有人的資料與入境卡連結。家族旅遊通常可以接受，但**請不要在試算表放護照號碼、生日等資料**。旅程結束後，記得取消「發佈到網路」並關掉 Drive 檔案的連結分享。
